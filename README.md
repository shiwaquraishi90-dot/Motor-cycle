# Raven Motors

## About the Project

Raven Motors is a modern and fully responsive motorcycle website.

This project was created as a group web development project using HTML, CSS, JavaScript, and Bootstrap.

The website is designed to provide a modern and attractive experience for motorcycle enthusiasts and works properly on different screen sizes.

## Website Name

**Raven Motors**

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Responsive Design

The website is completely responsive and works on different devices, including:

- Desktop
- Laptop
- Tablet
- Mobile Phone

The Bootstrap responsive grid system and CSS were used to make the website responsive on different screen sizes.

## Project Features

- Responsive navigation bar
- Modern motorcycle website design
- Hero sections
- Motorcycle information
- Blog and journal section
- Responsive images
- Responsive cards
- Interactive elements
- JavaScript functionality
- Bootstrap components
- Mobile-friendly design
